# Contributing

Open an issue or pull request with a focused addition or correction.

For prompts, include:

- The task and expected output.
- Required media and tools.
- Whether original timing is locked or editorial cuts are allowed.
- A copy-ready prompt with clear placeholders.
- Validation steps and known limitations.
- Whether it has been tested, and with which editor or rendering stack.

For skills and integrations, link to the publisher's repository or documentation. Distinguish published skills, ordinary tools, and proposed skills. Avoid unsupported compatibility claims.

Submit only content you have permission to share. Do not include private footage, credentials, personal file paths, or proprietary project files. Examples should use media that permits redistribution.

Keep writing clear and concise. Do not use em dashes or decorative numbering. By contributing, you agree that your contribution may be distributed under this repository's MIT License.
